API Documentation (Swagger Mock)

Integrate the ToolHub Pro processing capabilities directly into your shell apps or web scrapers. Pass your secrets key via header authentication: `Authorization: Bearer `.

POST /api/pdf/merge Merge PDF Files

Takes multiple PDF file streams inside a `multipart/form-data` payload and responds with a temporary download URL.

Request Example: curl -X POST https://api.toolhub.pro/v1/pdf/merge \ -H "Authorization: Bearer YOUR_API_KEY" \ -F "files=@document1.pdf" \ -F "files=@document2.pdf" Response: { "success": true, "message": "Documents merged successfully", "downloadUrl": "/downloads/output_92837bc.pdf", "totalPages": 18 }
POST /api/qr/generate Create Custom QR

Generate vector SVG/PNG codes with gradient parameters, custom dot overlays, and redirect tracking settings.

Request Example: curl -X POST https://api.toolhub.pro/v1/qr/generate \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "data": "https://company.com", "color1": "#09090b", "color2": "#2563eb", "dotStyle": "rounded", "isDynamic": true }' Response: { "success": true, "qrId": "qr_xyz982", "redirectUrl": "https://qr.toolhub.pro/xyz982", "svgData": "" }
